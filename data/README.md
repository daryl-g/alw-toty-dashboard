# Summary of each data file

**Note**: The [.xlsx](./ALW-Data.xlsx) did not have to be in this folder, but I forgot to include it in the `.gitignore` file before the first commit, so it's there. There isn't any confidential info, it's just a centralised spreadsheet that was used to store the FBRef tables before each sheet got splitted up into single `.csv` files.

| File name                            | Description                                                               | Source                                                                                    |
| ------------------------------------ | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| [AdvancedGK](AdvancedGK.csv)         | Advanced goalkeeping stats (Post-shot xG, etc)                            | [Advanced GK](https://fbref.com/en/comps/196/keepersadv/A-League-Women-Stats)             |
| [DefActions](DefActions.csv)         | Defensive stats (tackles, interceptions, etc)                             | [Defensive Actions](https://fbref.com/en/comps/196/defense/A-League-Women-Stats)          |
| [GCASCA](GCASCA.csv)                 | Goal- & Shot-created actions                                              | [Goal and Shot Creation](https://fbref.com/en/comps/196/gca/A-League-Women-Stats)         |
| [Goalkeeping](Goalkeeping.csv)       | Basic goalkeeping stats (Saves, etc)                                      | [Goalkeeping](https://fbref.com/en/comps/196/keepers/A-League-Women-Stats)                |
| [Misc](Misc.csv)                     | Any stats classified as miscellaneous (fouls, yellow/red cards, etc)      | [Miscellaneous](https://fbref.com/en/comps/196/misc/A-League-Women-Stats)                 |
| [Passing](Passing.csv)               | Passing & Chance creating stats (assists, passes attempted, etc)          | [Passing](https://fbref.com/en/comps/196/passing/A-League-Women-Stats)                    |
| [PassTypes](PassTypes.csv)           | Type of passes made (through balls, live/dead ball passes, etc)           | [Pass Types](https://fbref.com/en/comps/196/passing_types/A-League-Women-Stats)           |
| [PlayingTime](PlayingTime.csv)       | Players' minutes played & appearances                                     | [Playing Time](https://fbref.com/en/comps/196/playingtime/A-League-Women-Stats)           |
| [PositionMap](PositionMap.csv)       | Player positions from Soccerdonna & FBRef match logs                      | [Soccerdonna](https://www.soccerdonna.de/en/a-league-women/startseite/wettbewerb_WL.html) |
| [Possession](Possession.csv)         | Player possession stats (dribbles, carries, etc)                          | [Possession](https://fbref.com/en/comps/196/possession/A-League-Women-Stats)              |
| [Shooting](Shooting.csv)             | Attacking stats (goals, shots, xG, etc)                                   | [Shooting](https://fbref.com/en/comps/196/shooting/A-League-Women-Stats)                  |
| [TeamPossession](TeamPossession.csv) | Teams' possession % (for calculating possession-adjusted defensive stats) | Same as Possession                                                                        |
