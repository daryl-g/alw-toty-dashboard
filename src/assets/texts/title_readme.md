- This dashboard is a fan-made, unofficial project. This dashboard, or the creator of this dashboard, has no relations to the A-Leagues, the Australian Professional Leagues (APL), the Professional Footballers Australia (PFA), or Football Australia (FA) during the time this dashboard was developed. Therefore, any data, ratings, results generated using this dashboard are considered **unofficial** unless stated otherwise.

- All data used in this dashboard are from [Opta via FBRef](https://fbref.com/en/comps/196/A-League-Women-Stats) and were captured before the 2024-25 Grand Final (May 18th, 2025). Thus, this dashboard does not contain the latest transfers _(such as Sharn Freier &rightarrow; Wolfsburg, Lourdes Bosch &rightarrow; Denver Summit, or even Laini Freier's retirement)_.

  - Apparently, the date for when I captured the data does not matter that much. FBRef's data only includes the regular season and not the Finals series (for some reason!!!). Thus, there will be noticeable differences in per 90 stats and percentile ranks when comparing to Fotmob's data even though both Fotmob and FBRef use the same source (Opta).

**Data privacy note**:
The app uses Streamlit's session data to customise your experience and make it better and smooth. It is different to cache data that the app does not store any data on your device, it only uses your browser's session storage to store the data listed below to prevent them from being reset between each reruns that are triggered by Streamlit. Those session data will be deleted after you close the current tab or close the browser, so nothing is stored on your device after you interact with the app.

Data stored using session data:

- Chosen app theme using the widget on the Home page, which is applied for all widgets, background, visualisations, etc.
- Selected team, player for all pages, and selected position for the Role Ratings page.
